# INF512-Unidad1-POO

Este proyecto es para la asignatura Lenguaje de Programación I.
El objetivo es aplicar los conceptos fundamentales de la Programación
Orientada a Objetos (POO) en C#, y demostrar el uso del control de
versiones con Git y GitHub.

## Descripción

Este repositorio contiene la clase `Estudiante`, que modela un estudiante
universitario con sus atributos (nombre, edad, matrícula) y sus métodos
(inscribir materia, entregar tarea, mostrar información).

## Conceptos aplicados

- Clases y objetos
- Estado y comportamiento
- Encapsulamiento (atributo `edad` privado, validado mediante una propiedad)

## Cómo ejecutar

1. Clonar el repositorio
2. Abrir el proyecto en Visual Studio o compilar con `dotnet run`
3. Ejecutar `Estudiante.cs`
